## 与原实现的**有意偏离**（不是 bug，验收时请勿当作缺陷）

1. **没有本地 HTTP 服务与内核子进程**：全部改成 Tauri IPC（`invoke`）。
   因此"后台服务异常 → 重启内核"整套机制不存在，进程即应用。
2. **界面栈换成纯 Rust**：Leptos(WASM) 取代 Vue 3，无 Node/npm、无 vendor JS；
   图表、Markdown、拖拽排序、日期选择都是 Rust 实现。
3. **设置页用顶部 tabs**（原实现是左侧导航）。
4. **股票资金记录的 `created_at` 单调化**（`max(now, max+1)`），让 Go 那边一条回填日期的测试变得确定。
5. **`page`/`page_size`/`recent` 接受字符串或数字**（原 HTTP 层两种都能过）。
6. **编辑记账记录 = 先建后删**，与原 Vue 行为一致（不是原地 UPDATE）。
7. **gin 绑定失败的原始报错文案无法复刻**（那一层在 IPC 下不存在），改为等价的用户可见文案。
8. **`chart_lines` 的条件在客户端省略时返回 `null`**（原实现同样如此），与"显式传空数组"不同。
9. **HEIC 转换在界面层**（canvas 交给 WebView2/系统解码器），后端只接受 JPEG/PNG/GIF/WebP。
10. **自动更新是自研实现**（GitHub Releases + `asset.digest` sha256），不用 `tauri-plugin-updater`，
    不需要签名密钥与 `latest.json`。

## 数据兼容的边界

- 只保证**最新 schema（v0.27+）**：`transactions.db` 不存在时按 `fixtures/schema/fresh_v0_27.sql` 建库；
  已存在时**只读校验**，绝不改结构。
- 更早版本的工作空间会被明确拒绝，**没有迁移代码**（这是本轮明确要求删掉的部分）。
- 报告问题时请附上工作空间目录下的 `transactions.log`（或 `~\.transactions.log`）。
  默认只记 `info`；需要看命令级参数时用 `$env:RUST_LOG='debug'` 启动，
  日志里会出现 `IPC tr_query ledger=... offset=... limit=... items=...` 这类行
  （目前 `config_get` / `workspace_open` / `ledger_list` / `tr_query` 有埋点）。
